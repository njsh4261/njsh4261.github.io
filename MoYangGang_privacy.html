MoYangGang 개인정보처리방침

시행일: 2026년 11월 6일

1. 앱 소개

MoYangGang은 개발자 njsh4261이 자기 PC의 작업 파일을 자기 Google Drive에 백업하려고 만든 개인용 OAuth 클라이언트입니다. 오픈소스 도구 rclone과 restic이 이 클라이언트로 Google Drive에 접속합니다. 일반 사용자에게 배포하거나 판매하는 서비스가 아니며 개발자 본인 계정만 사용합니다.

2. 접근하는 Google 사용자 데이터

이 앱은 Google Drive API의 https://www.googleapis.com/auth/drive.file 범위만 요청합니다. 이 범위로는 이 앱이 직접 만든 파일과 폴더에만 접근하며 Drive에 있는 다른 파일은 읽거나 바꿀 수 없습니다. 이름, 이메일 주소, 연락처, 위치 같은 그 밖의 개인정보는 요청하지 않습니다.

3. 데이터 사용 목적

백업 파일 업로드, 백업 목록 확인, 복원을 위한 다운로드, 보존 기간이 지난 백업 삭제에만 씁니다. 백업 파일은 업로드 전에 restic이 개발자 PC에서 암호화하므로 Drive에는 암호화된 데이터만 저장됩니다.

4. 저장과 보관

  • OAuth 토큰은 개발자 PC의 rclone 설정 파일에만 저장합니다.
  • 백업 데이터는 개발자 본인의 Google Drive에만 저장합니다.
  • 개발자가 운영하는 별도 서버는 없으며 어떤 데이터도 다른 곳으로 전송하지 않습니다.

5. 공유와 제3자 제공

Google 사용자 데이터를 제3자에게 판매하거나 공유하거나 넘기지 않습니다. 광고, 분석, 사용자 추적에 쓰지 않으며 AI 모델 학습에도 쓰지 않습니다.

6. Google API 서비스 사용자 데이터 정책 준수

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

7. 접근 권한 철회와 삭제

Google 계정의 서드파티 연결 관리에서 언제든 이 앱의 접근 권한을 철회할 수 있습니다. 이 앱이 만든 백업 파일은 Google Drive에서 직접 지울 수 있습니다.

8. 변경과 문의

이 방침을 바꾸면 이 페이지를 고치고 시행일을 갱신합니다. 문의는 GitHub 프로필 njsh4261로 해 주십시오.

MoYangGang Privacy Policy

Effective date: November 6, 2026

1. About this app

MoYangGang is a personal OAuth client created by the developer njsh4261 to back up work files from the developer's own PC to the developer's own Google Drive. The open source tools rclone and restic use this client to connect to Google Drive. It is not distributed or sold to the public and is used only with the developer's own account.

2. Google user data accessed

This app requests only the Google Drive API scope https://www.googleapis.com/auth/drive.file. With this scope it can access only the files and folders it created, and it cannot read or modify any other file in Drive. It does not request any other personal information such as name, email address, contacts, or location.

3. How the data is used

The data is used only to upload backup files to Drive, list them, download them for restores, and delete backups past their retention period. restic encrypts backup files on the developer's PC before upload, so Drive stores only encrypted data.

4. Storage and retention

  • OAuth tokens are stored only in the rclone configuration file on the developer's PC.
  • Backup data is stored only in the developer's own Google Drive.
  • The developer runs no separate server, and no data is sent anywhere else.

5. Sharing and third parties

Google user data is not sold, shared, or transferred to any third party. It is not used for advertising, analytics, or user tracking, and it is not used to train AI models.

6. Compliance with the Google API Services User Data Policy

MoYangGang's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deletion

Access can be revoked at any time from third-party connections in your Google Account. Backup files created by this app can be deleted directly in Google Drive.

8. Changes and contact

If this policy changes, this page will be updated along with the effective date. For questions, please use the GitHub profile njsh4261.
